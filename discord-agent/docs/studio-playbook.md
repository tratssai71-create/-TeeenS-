- ブラウザ操作は、必ず登録済みの Playwright の道具(playwright/browser_navigate、browser_snapshot、browser_click、browser_type など)を使う。cua_repl は使わない。
- 対象プロジェクトのURLが分かっているときは、一覧やダッシュボードを経由せず、編集画面のURLを直接開く。
- 画面の左に「レイヤー」パネルがある。名前の検索欄で、探したい要素(例: メインコピー、見出し)を検索して選ぶ。
- 文字の変更は、レイヤーを選ぶと右パネルに出る「テキスト」欄の文字を書き換える。キャンバス上の文字を直接ダブルクリックして編集してもよい。
- 変更後は、キャンバスの表示が変わったことを、スクリーンショット1枚で確認する。何度も撮り直さない。
- 画面右上の黒い「公開」ボタンは、通常の編集作業では押さない。タスクの題が「本番公開」で、公開を承認済みと書かれている場合だけ押す。
- 想定外の画面(ログイン画面、確認ダイアログ、エラー)が出たら、推測で進めず、状況を報告して止まる。
- 依頼にない箇所は、変更しない。
