**📖 コマンド表(#designer-chat)**
普通の言葉でも、頼めます。コマンドは、近道です。

**▼ 作る・直す**
`!build 3` 仕様書の3番目のセクションを、作る(見本の画像つき)
`!auto 3` 作る → 検査 → 直す を、自動で(最大3回)。詰まったら、止まって聞く
`!auto 3-5` 3から5まで、順に自動で。`!auto all` で、全部(合っているものは飛ばす)
`!fix 3` 検査で見つかった「文字・スタイルの違い」を、直す
`!fix 3 配置` 「配置のずれ」を、直す
`!new` 会話を、リセット(新しい指示を反映したいときも)
`!stop` 作業を、止める

**▼ 見る・確かめる(Codexは使わない。上限中でも使える)**
`!check 3` セクション3を、仕様書と見比べる(文字・色・大きさ・配置)
`!progress` 全セクションの進み具合の表
`!compare` 元とSTUDIOを、左右に並べた画像と、見た目の近さ(🟢🟡🔴)
`!shot` いまのSTUDIOの画面
※ STUDIOの画面を「モバイルサイズ」にすると、スマホ用の仕様で検査します

**▼ 決める・育てる**
`!accept 料金プラン 色` 「この違いは、これでよい」と記録(検査から外れる)
`!accept Landing 画像` 「文字ではなく、画像で代用した」と記録(「無い」扱いにしない)
`!lessons` エージェントが見つけた、コツの記録
`!health` 動かす前の点検(Chrome・STUDIO・仕様書・Codex) / `!help` このコマンド表 / `!session` 会話の番号 / `!ping` 生きているか
`!limit clear` Codexの上限の記録を消す

**📖 コマンド表(#command)**
`!quick 依頼` 計画を省いて、すぐ作業(例: 文字の変更)
`!status` いまの状況 / `!report` 今日の件数と、段階ごとの秒数
`!halt` 全部止める / `!resume` 再開 / `!limit` 上限の確認
公開は、#approve の「公開する」を、人が押したときだけ

**📖 流れの目安**
1. `!new` → `!build N`(または `!auto N`)
2. `!check N` で確かめる → 違いがあれば `!fix N`(配置は `!fix N 配置`)
3. 全部できたら `!compare` で、全体を見る。画像の差し替えは、人の作業
